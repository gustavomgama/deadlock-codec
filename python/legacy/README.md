# Legacy scripts

One-off debug helpers kept for reference. Not part of the supported CLI, not imported by any current script.

- `decode_bin.py` — dumps `build.bin` (not in this repo)
- `decode_build2.py` — dumps `build2.bin` (not in this repo)
- `decode_pb.py` — dumps a base64 protobuf from `argv[1]`

Use `../decode_build_code.py` for actual build codes.
